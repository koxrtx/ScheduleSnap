# Schedule Snap(未定）

## サービス概要

**Schedule Snap** は、幼稚園・保育園・学校などから配布される予定表をスマートフォンで撮影するだけで、AIが予定を読み取り、Googleカレンダーへ簡単に登録できるWebアプリです。

紙の予定表を一件ずつ手入力する手間をなくし、忙しい保護者のスケジュール管理をサポートします。

---

## このサービスへの思い・作りたい理由

子どもが幼稚園に通い始めてから、毎月のお便りや年間行事予定表など、多くの紙の予定表を受け取るようになりました。

予定を忘れないようにするためには、Googleカレンダーへ一件ずつ登録する必要がありますが、

- 夏祭り
- お弁当の日
- 午前保育
- 保護者会
- 遠足
- 発表会

などを毎回手入力するのは想像以上に時間がかかります。

また、忙しい日々の中で入力を後回しにしてしまい、予定を登録し忘れてしまうこともありました。

そこで、「予定表を撮影するだけでAIが内容を理解し、Googleカレンダーへ登録できれば、保護者の負担を大きく減らせるのではないか」と考え、このサービスを作成しました。

---

## ユーザー層

- 幼稚園・保育園に通う子どもがいる保護者
- 小学校低学年の子どもがいる保護者
- 家族の予定をGoogleカレンダーで管理している方
- 紙の予定表をデジタルで管理したい方

---

## サービスの利用イメージ

1. 幼稚園・保育園・学校から配布された予定表を撮影
2. AIが画像から予定を抽出・解析
3. 抽出した予定を一覧で確認
4. 必要に応じて内容を編集
5. Googleカレンダーへ登録

---

## サービスの差別化ポイント・推しポイント

- AIが予定表の内容を解析し、予定を自動で抽出
- Googleカレンダーへワンクリックで登録
- OCRによる文字認識だけでなく、AIが予定の内容を理解して整理
- 登録前に内容を確認・編集できるため誤登録を防止
- 保育園・幼稚園・学校特有の予定（お弁当・午前保育・保護者会など）にも対応
